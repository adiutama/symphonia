# Overlay Switcher; Editor vs Background attention

Only one Overlay is visible at a time. The Overlay Switcher lists live Editor and Background Overlays so the Operator can jump between them.

Editor and Background CLIs share peek/hide (process stays alive) but get **different UI treatment**: the Editor is the high-attention craft surface; Background CLIs are lighter peeks (e.g. servers). The product rule is: Editor > Background in attention.
