# Symphonia brand mark

**Locked concept:** #11.1 Spiral spine

Brass (`#c4a25a`) continuous stroke on an ink field (`#12151c` → `#2a3142`). Reads as a clef-like spine; some see a reverse sword with a tail — both fine.

## Files

| Path | Role |
|------|------|
| `symphonia-icon.svg` | Master app icon (full-bleed square) |
| `symphonia-mark.svg` | Transparent mark |
| `symphonia-icon-small.svg` | Simplified for 16/32 |
| `render-appicon.swift` | Rasterize into `AppIcon.appiconset` |
| `symphonia-icon-1024.png` | Preview raster (regenerated by the script) |

## Regenerate app icons

From repo root:

```bash
swift docs/brand/render-appicon.swift "$(pwd)"
```

Then build Symphonia in Xcode (⌘R). macOS may cache Dock icons — relaunch or bump the build if the old placeholder sticks.
